# Distributed Wagering Processor

Serviço financeiro distribuído que processa transações de apostas recebidas de múltiplos provedores de jogos.

Stack: Bun, TypeScript (strict), NestJS, PostgreSQL, MikroORM, AWS SQS (MiniStack) e Docker Compose.

Instruções de setup e execução serão adicionadas conforme o projeto evolui.
